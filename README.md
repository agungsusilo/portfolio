# Agung Susilo — Portfolio

Personal portfolio site for Agung Susilo, SDET & Software Engineer.

Built with vanilla HTML, CSS, and JavaScript. No build step required — deploy directly via GitHub Pages.

## Deploy on GitHub Pages

1. Go to repo **Settings → Pages**
2. Set source to **Deploy from a branch**
3. Branch: `main`, folder: `/ (root)`
4. Save — the site will be live at `https://agungsusilo.github.io/portfolio`
